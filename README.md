# Hunt Duck AR

Experiencia web AR de **Hunt Duck**, publicada con GitHub Pages.

- **Página en vivo:** https://arcangel221001-wq.github.io/hunt-duck-ar/
- **Repositorio:** https://github.com/arcangel221001-wq/hunt-duck-ar

El archivo `index.html` es autocontenido: incluye el modelo 3D en base64.
En el celular, abre la página desde el QR (botón **QR** dentro de la app) o escanea el QR incluido en `qr-hunt-duck-ar.png`.

La cámara requiere HTTPS y permiso del navegador; GitHub Pages cumple con HTTPS.

## Actualizar

Reemplaza `index.html`, haz commit y `git push origin main`. Pages se actualiza en unos segundos.
