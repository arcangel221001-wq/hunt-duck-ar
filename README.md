# Hunt Duck

Sitio web del videojuego **Hunt Duck** con su experiencia de realidad aumentada, publicado con GitHub Pages.

- **Sitio del juego:** https://arcangel221001-wq.github.io/hunt-duck-ar/
- **Experiencia AR:** https://arcangel221001-wq.github.io/hunt-duck-ar/ar.html
- **Instagram:** [@huntduck_oficial](https://www.instagram.com/huntduck_oficial)

## Archivos

- `index.html`: sitio con todo el contenido de la presentación (historia, mundo, personajes, jugabilidad, arte conceptual, branding y plataforma) y la sección de AR.
- `ar.html`: experiencia AR autocontenida (incluye el modelo 3D en base64): menú de preguntas, cámara con carrete de fotos y QR.
- `assets/`: imágenes de la presentación, logos, favicon y `modelo.glb` (vista previa 3D del sitio).

La cámara y la AR requieren HTTPS y permiso del navegador; GitHub Pages cumple con HTTPS.

## Actualizar

Reemplaza los archivos, haz commit y `git push origin main`. Pages se actualiza en uno o dos minutos.
